# 0006 — Trilha sintetizada com Web Audio
- **Status:** aceita
- **Data:** 2026-10-16

## Contexto
O briefing pede música sem direitos autorais gerada com Web Audio, a partir do `RomanticAudioEngine` com 4 progressões.

## Decisão
O `RomanticAudioEngine` foi completado com:
- agendamento antecipado (aguenta aba em segundo plano);
- timbre por estilo: Piano, Cinema, Caixinha de música, Serenata;
- reverb e eco;
- crossfade ao trocar de estilo;
- *ducking* sob a voz.

Volume base 0,36; durante a fala cai para 50%, ajuste de 2026-10-16 porque estava baixo.

## Consequências
- Sem custo nem risco de direitos autorais. Arquivo nenhum para baixar.
- A qualidade depende do ouvido: ajustar timbres e volumes testando no celular.
